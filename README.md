# 🗳️ Sistema Eleitoral em Python com Tkinter

Projeto de um sistema de votação desenvolvido em **Python** com interface gráfica em **Tkinter** e banco de dados **SQLite**.

> Projeto com foco em estudo, prática e portfólio.

---

## 📌 Sobre

A ideia deste projeto é criar um **sistema eleitoral local** que permita:

* cadastrar candidatos
* cadastrar eleitores
* registrar votos
* apurar resultados

A versão inicial será feita com:

* **Python**
* **Tkinter**
* **SQLite**

No futuro, o projeto poderá evoluir para uma versão web.

---

## 🚀 Tecnologias

* **Python 3**
* **Tkinter**
* **SQLite3**
